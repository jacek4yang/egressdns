# Fuzzing

These targets cover every parser that consumes data EgressDNS did not produce itself.

Fuzzing requires a nightly toolchain and `cargo-fuzz`, which is why this crate is outside
the main workspace: `cargo build --workspace` on the pinned stable toolchain never touches
it.

```bash
rustup toolchain install nightly
cargo install cargo-fuzz

cd fuzz
cargo +nightly fuzz list
cargo +nightly fuzz run dns_message -- -max_total_time=60
```

| Target                    | What it protects                                              |
| ------------------------- | ------------------------------------------------------------- |
| `dns_message`             | Every byte that reaches the UDP/TCP listener                   |
| `seed_parser`             | Third-party candidate lists, which have no authority at all    |
| `cloudflare_prefix_json`  | The official prefix API and text lists                         |
| `config_toml`             | Configuration parsing, plus the "never an open resolver" rule  |
| `dataset_parser`          | Hosts files, category files and internal zone construction     |
| `admin_protocol`          | The local administration socket                                |
| `der_walker`              | Certificate SPKI and issuer extraction                         |

A crash reproduces with:

```bash
cargo +nightly fuzz run <target> fuzz/artifacts/<target>/<crash-file>
```

Seed corpora are not committed. `scripts/seed-fuzz-corpus.sh` builds one from the test
fixtures and from messages generated by the integration tests.
